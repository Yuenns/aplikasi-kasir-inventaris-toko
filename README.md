# aplikasi-kasir-inventaris-toko
tugas proyek akhir pemrograman dasar C++

fitur
1).input_barang
Program ini menerima data barang dari pengguna (nama, kode, jumlah, dan harga), lalu menyimpannya ke file teks barang.txt. Data lama tidak terhapus, karena data baru selalu ditambahkan di akhir file.

 2).stock
 Membaca file barang.txt dan menampilkan semua data barang yang tersimpan (nama, kode, jumlah, dan harga) dalam bentuk daftar.

 3).kasir
 Sistem kasir sederhana: pembeli memilih barang dan jumlah, membayar, lalu program menampilkan kembalian dan struk pembayaran.
